# 景区安全智能监测与无人机救援平台

本仓库包含景区基站监测平台、无人机端控制与视觉服务、Jetson 基站视频网关，以及目标识别模型训练工具。

## 目录

- `ground_station/`：Windows 地面端云平台、地图、告警和任务接口。
- `raspberry_pi_vision/`：树莓派视频识别、MAVLink 遥测及无人机控制页面。
- `jetson_station/`：Jetson 基站摄像头网关的安装与检查脚本。
- `model_training/`：目标识别模型训练与数据处理工具。

## 本地启动

Windows 地面端：

```powershell
.\启动基站监测平台.cmd
```

默认访问地址：`http://127.0.0.1:8090/`。

设备端部署说明分别位于各子目录的 `README.md` 或安装说明中。

## 配置与安全

真实摄像头密码、控制 PIN、网页登录密码、令牌和 SSH 私钥不会纳入版本库。部署前请复制对应的 `*.env.example` 为本机 `*.env` 文件并填写实际值。

飞控远程控制默认应保持关闭；完成设备身份校验、权限控制、链路心跳和现场安全测试后才能启用。

## 大文件

模型、训练数据、Python 虚拟环境、离线依赖和 MediaMTX 二进制未包含在源码包中。请根据各端说明单独安装或从正式发布页下载。
