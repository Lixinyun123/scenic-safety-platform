# 落水待救人员专用模型训练

模型类别只有一个：`person_in_water`。它表示“画面中疑似有人处于水里，需要进一步确认”，不能仅凭单帧图像医学判断一个人是否真的溺水。

## 1. 安全采集

- 只使用救生衣、救生绳、岸边监护、浅水受控摆拍或人体假人，不进行真实溺水模拟。
- 使用最终无人机和 SJCAM 的近似高度、俯拍角度、焦距和白天光照。
- 正样本应覆盖：仰漂、趴伏、仅头肩露出、挥手、被浪花遮挡、不同衣服颜色和不同距离。
- 负样本应覆盖：空水面、反光、浪花、浮标、轮胎、救生圈、漂浮垃圾、船、岸边人员和船上人员。
- `train` 与 `val` 必须来自不同拍摄场次或不同视频，禁止把同一段视频的相邻帧随机分到两边。

建议第一轮至少准备：训练正样本 500 张、负样本 500 张；验证正样本 150 张、负样本 150 张。100/30只是脚本允许试跑的最低门槛，不是最终质量标准。

## 2. 放入视频并抽帧

- 训练视频放到 `raw_videos/train`。
- 独立场景的验证视频放到 `raw_videos/val`。

```powershell
python scripts/extract_frames.py --seconds 1
```

图片会进入 `dataset/images/train` 和 `dataset/images/val`。抽帧间隔不要太密，否则模型只是记住相邻画面。

## 3. 标注规范

- YOLO 类别编号固定为 `0`。
- 框住人在水面可见的完整区域；身体被水遮住时不要猜测水下范围。
- 救生圈只框人，不把救生圈扩大进人员框。
- 难以确认是不是人的极小目标先不标，单独放入“待复核”目录。
- 没有落水人员的负样本保留图片，标签文件缺失或为空即可。
- 岸边、码头和船上的人不标注，他们属于重要负样本。

标注结果放到与图片同名的 `dataset/labels/train/*.txt` 或 `val/*.txt`。

## 4. 开始训练

在安装了 CUDA 版 PyTorch 和 Ultralytics 的环境中执行：

```powershell
python train.py --epochs 120 --batch 16 --imgsz 640
```

RTX 4070 Laptop 8GB 建议先用 batch 16。如果显存不足，改为 8；不要降低 `imgsz=640` 来解决显存问题。

训练后重点查看验证集的 Precision、Recall、mAP50，以及负样本误报。搜救系统优先避免漏检，因此不能只看 mAP，还要逐张检查漏检图片。
